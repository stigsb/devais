## 1. nRF52840 PDM clock — VERIFIED

Source: nRF52840 Product Specification, PDM chapter, `PDMCLKCTRL.FREQ`
(https://docs.nordicsemi.com/r/bundle/ps_nrf52840/page/pdm.html) — VERIFIED.

| Enum | Value | PDM_CLK | Note in PS |
|---|---|---|---|
| 1000K | 0x08000000 | 32 MHz / 32 = 1.000 MHz | |
| Default | 0x08400000 | 32 MHz / 31 = 1.032 MHz | Nominal clock for RATIO=Ratio64 |
| 1067K | 0x08800000 | 32 MHz / 30 = 1.067 MHz | |
| 1231K | 0x09800000 | 32 MHz / 26 = 1.231 MHz | |
| 1280K | 0x0A000000 | 32 MHz / 25 = 1.280 MHz | Nominal clock for RATIO=Ratio80 |
| 1333K | 0x0A800000 | 32 MHz / 24 = 1.333 MHz | |

**Correction to the brief's premise.** The nRF52840 is *not* limited to 1.000/1.032/1.067 MHz.
`RATIO` selects Ratio64 or Ratio80, and PDMCLKCTRL offers 1.231/1.280/1.333 MHz for the Ratio80
family. 1.032 MHz / 64 = 16.125 kHz; 1.280 MHz / 80 = 16.0 kHz. Both give ~16 kHz voice audio.
This matters: several in-stock mics have a 1.1 or 1.2 MHz minimum clock and are unusable at
1.032 MHz but fine at 1.280 MHz.

Also VERIFIED from the same chapter: PDM clock jitter ~20 ns, duty cycle 40–60 %; the electrical
spec table names fPDM,CLK,64 = 1.032 MHz and fPDM,CLK,80 = 1.280 MHz.

Sleep behaviour detail worth knowing for a push-to-talk design: with CLK stopped and SELECT tied
to GND, DATA goes high-impedance; with SELECT tied to VDD, DATA is pulled to GND. Either is safe;
tying SELECT low keeps the nRF PDM DIN pin floating when idle, so enable the nRF's internal
pull-down or accept the float. VERIFIED from the Sleep Mode section.

Why it wins: it is the only in-stock bottom-port PDM part whose normal (Standard) mode starts at
**1.0 MHz**, so it runs directly at the nRF52840 reset-default 1.032 MHz with RATIO=Ratio64 —
no clock re-plan, and the same part also covers 1.280/Ratio80 if you prefer exactly 16 kHz.
It additionally gives a genuine 400–800 kHz Low-Power always-on mode at 185 µA, which the
nRF cannot clock directly from PDMCLKCTRL but which is reachable with a PWM/timer-driven clock
if a wake-word path is ever added.

Drawback: ~$1.29 @10 is the most expensive of the viable set, and the Infineon-class 69–71 dB
SNR is not on offer here (64.5 dBA).

**Clock caveat (the reason this is the fallback, not the pick).** 900 kHz–1.1 MHz is a dead band
for this part. The nRF's 1.000/1.032/1.067 MHz options all land in that gap. Usable nRF settings
are therefore `PDMCLKCTRL=1280K` with `RATIO=Ratio80` (16.000 kHz) or `1231K`/`1333K` with
Ratio80 (15.39 / 16.66 kHz). 1.280 MHz / Ratio80 is the clean choice.

Upsides over the T3902: 66 dB(A) SNR (1.5 dB better), less than half the price, 1 µA sleep
instead of 12 µA, and a wider 1.6 V supply floor. Downside: only 1,830 in stock and a
second-tier vendor.

## 4. Board notes for the recommended part

- Footprint: LGA-5(3.5x2.7) — EasyEDA/JLCPCB library symbol + footprint exist for C3171752 (VERIFIED
  on the JLCPCB part page), so the JLCPCB footprint can be imported rather than hand-drawn.
- Sound hole in the daughterboard: **0.8 mm** is a good middle of the 0.5–1.0 mm recommended range —
  comfortably above the 0.375 mm package port and still small enough to keep a gasket seal simple.
  It faces the enclosure's 1.5 mm acoustic hole; leave the mic's own port unobstructed and keep
  the acoustic path short.
- Solder paste: mask the sound hole out of the stencil (no paste on or in the hole).
- Decoupling: 0.1 µF X7R 0402 from VDD (pin 5) to GND, placed against pin 5.
- SELECT (pin 2): tie to GND for right channel / data on CLK falling edge. Keep it a hard tie, not
  a floating net.
- CLK and DATA: no series termination or pull resistors needed at this trace length. Do not add a
  pull-up/pull-down on DATA.
- Assembly: JLCPCB tags this part "assembly difficulty: High" and it is MSL 1, which is the easy end
  for moisture. Expect the usual MEMS-mic caveats: no board wash after reflow, limited reflow cycles.
